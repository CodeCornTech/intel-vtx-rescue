# Security and private reports

Please use GitHub's private vulnerability reporting for security issues once the repository is published and the maintainer enables that setting. If it is not enabled, open an issue asking the maintainer for a private reporting channel, without vulnerability details or private host data.

Supported project version: 0.1.x. The active write guard covers only the configuration recorded in the README.

Do not attach customer BIOS exports or credentials. These scripts use an already-installed firmware configuration tool with administrator privileges. Review both the project source and the provenance of that installation before use. The repository does not download or execute Intel binaries automatically.
